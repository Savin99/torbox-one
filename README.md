# TorBox Telegram Bot

Многопользовательский Telegram-пульт для TorBox. Каждый человек подключает собственный TorBox API key, видит только свои загрузки и получает только свои уведомления. Бот параллельно ищет через прямой NNM-Club и настроенные индексеры Prowlarr, собирает единый топ, добавляет `.torrent` или magnet. Работает через long polling: домен, webhook и открытый порт не нужны.

## Что готово

- Все основные действия находятся в inline-меню под сообщением бота; постоянная клавиатура под строкой ввода отключена.
- Автоматическое оформление профиля: имя, короткое и полное описание.
- Поиск кнопкой, командой `/search название` или обычным текстом сразу по нескольким источникам.
- Обычный поиск с каталогом фильмов: запрос удаляется из чата, варианты и релизы показывает сам бот в одном экране.
- Кнопка `🔎 Поиск` под сообщением одним нажатием открывает поиск с постерами прямо в строке ввода.
- Единый рейтинг по совпадению с запросом, качеству, озвучке, сидам и доверию к источнику.
- Дедупликация одинаковых релизов по info-hash, а без него — по названию и размеру.
- Карточка релиза и прямое добавление по явно подписанной кнопке; подтверждение обязательно только для удаления.
- `/torrents`: список с пагинацией, статусом, прогрессом, размером и скоростью.
- Подробная карточка загрузки, обновление, reannounce и продолжение приостановленной загрузки.
- Двухшаговое удаление строго выбранной загрузки.
- Ручная лента и автоматическая пересылка новых уведомлений TorBox.
- Личная привязка TorBox через `/connect`: ключ проверяется перед сохранением, сообщение с ним сразу удаляется, аккаунты и фоновое состояние изолированы по Telegram ID.

## Настройка Telegram и TorBox

1. Открой `@BotFather`, выполни `/newbot`, задай имя и уникальный username, оканчивающийся на `bot`. Сохрани HTTP API token.
2. Возьми числовой Telegram ID администратора. Для этого можно использовать уже известный ID аккаунта или бота, показывающего `user_id`.
3. В TorBox администратора открой **Settings → API Keys** и скопируй API key. Этот ключ остаётся резервным ключом владельца; остальные люди подключат свои ключи через Telegram.
4. Запусти безопасную интерактивную настройку (токены при вводе не отображаются):

```bash
cd /root/projects/torbox-telegram-bot
./scripts/configure-credentials.sh
```

Скрипт запросит три обязательных значения и сохранит их в `.env` с правами `0600`:

```dotenv
TELEGRAM_BOT_TOKEN=123456:replace_me
TORBOX_API_KEY=replace_me
OWNER_TELEGRAM_ID=123456789
MULTI_USER_ENABLED=true
```

При повторном запуске можно нажать Enter, чтобы оставить уже сохранённое значение. Для подготовки файла systemd напрямую используй:

```bash
sudo ./scripts/configure-credentials.sh --output /etc/torbox-telegram-bot.env
```

`PROWLARR_*`, `TELEGRAM_BOT_NAME`, `TORBOX_NOTIFICATIONS_ENABLED`, `NOTIFICATION_POLL_SECONDS` и `LOG_LEVEL` необязательны. `MULTI_USER_ENABLED=true` разрешает другим людям открыть личный чат с ботом и подключить собственный TorBox. Не добавляй `.env` в Git.

### Как подключается новый пользователь

1. Открывает личный чат с ботом и нажимает **Start**.
2. Выбирает `🔑 Аккаунт` или отправляет `/connect`.
3. Отправляет свой ключ из **TorBox → Settings → API Keys**.

Бот удаляет сообщение с ключом до проверки и никогда не показывает ключ обратно. Проверенные пользовательские ключи хранятся отдельно от обычного состояния в `credentials.json` с правами `0600`. Это файловая защита операционной системы, поэтому доступ к серверу и резервным копиям должен быть только у администратора. Команда `/account` позволяет заменить ключ или удалить его; удаление ключа не удаляет загрузки из TorBox.

При запуске бот сам удаляет старый webhook, регистрирует команды, кнопку меню и описание профиля. Аватар при желании один раз задаётся через `@BotFather` → **Edit Bot → Edit Botpic**.

### Каталог фильмов и поиск с постерами

Основной поиск запускается кнопкой `🔎 Поиск` под сообщением: Telegram сразу переводит курсор в строку ввода. Пока строка пустая, бот показывает до 20 популярных сейчас фильмов и сериалов с постерами; с первого введённого символа включает релевантный поиск по названию. Для названий, года, рейтинга, стран и жанров зарегистрируй бесплатный ключ на `kinopoiskapiunofficial.tech` и добавь:

```bash
./scripts/configure-catalog.sh
```

Скрипт принимает ключ скрытым вводом и сохраняет `.env` с правами `0600`. Либо добавь значение вручную:

```dotenv
KINOPOISK_API_KEY=replace_me
```

Дополнительно можно вручную использовать `@tor_boxai_bot название` прямо в строке ввода. Это системный inline mode Telegram с постерами: выбранная карточка публикуется от имени пользователя с пометкой бота. Чтобы его включить:

1. Открой `@BotFather` и отправь `/setinline`.
2. Выбери `@tor_boxai_bot`.
3. Введи подсказку, например `Название фильма или сериала`.

Inline-результаты персональны для отправителя и доступны всем допущенным пользователям. Без `KINOPOISK_API_KEY` или без `/setinline` обычный текстовый поиск продолжит работать, но кнопка с постерами не появится.

## Мультипоиск для РФ через Prowlarr

Prowlarr — открытый менеджер индексеров с единым API. Бот оставляет прямой NNM резервом и параллельно получает результаты всех включённых в Prowlarr трекеров. Отказ одного источника не ломает общий поиск.

Быстрый запуск через Docker:

```bash
docker compose -f docker-compose.prowlarr.yml up -d
```

Открой `http://127.0.0.1:9696`, заверши первый запуск и добавь источники через **Indexers → Add Indexer**. На удалённом VPS сначала сделай SSH-туннель `ssh -L 9696:127.0.0.1:9696 user@server`: compose специально не публикует панель в интернет. Практичный русскоязычный набор:

- **RuTracker.org** — основной приоритет, потребуется аккаунт.
- **Kinozal (M)** — magnet-вариант, потребуется аккаунт.
- **RuTor** — публичный резерв.
- **BigFANGroup** — публичный источник фильмов и сериалов.
- **Byrutor** и **PC-torrent** — публичные источники игр.
- **MegaPeer** — публичный источник фильмов и сериалов, но на некоторых VPS потребует FlareSolverr из-за Cloudflare.
- **seleZen** — дополнительный источник, потребуется аккаунт.
- **NNM-Club** уже подключён прямо в боте; второй раз добавлять необязательно.

У каждого индексера нажми **Test**, затем **Save**. API key Prowlarr находится в **Settings → General → Security**.

Если Prowlarr запущен этим compose-файлом, перенеси адрес и сгенерированный API-ключ в `.env` безопасно, без их вывода в терминал:

```bash
./scripts/sync-prowlarr.sh
```

Или задай подключение вручную:

```dotenv
NNM_ENABLED=true
PROWLARR_URL=http://127.0.0.1:9696
PROWLARR_API_KEY=replace_me
PROWLARR_INDEXER_IDS=
```

Пустой `PROWLARR_INDEXER_IDS` означает поиск по всем включённым индексерам. Для ограничения впиши их числовые ID через запятую, например `1,3,5`. Download Client внутри Prowlarr не нужен: релиз забирает бот и отправляет прямо в TorBox.

После изменения `.env` перезапусти бота. В выдаче будет указан конкретный трекер, а сверху — количество ответов от каждого поискового клиента.

## Локальный запуск

```bash
cd /root/projects/torbox-telegram-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./scripts/run-bot.sh
```

После старта открой личный чат с ботом и нажми **Start**. Быстрая проверка: `/status`, затем поиск по кнопке.

## Постоянный запуск через systemd

Команды рассчитаны на Debian/Ubuntu и выполняются на сервере:

```bash
sudo install -d -m 0755 /opt/torbox-telegram-bot
sudo cp torbox_tg_bot.py requirements.txt /opt/torbox-telegram-bot/
sudo python3 -m venv /opt/torbox-telegram-bot/.venv
sudo /opt/torbox-telegram-bot/.venv/bin/pip install -r /opt/torbox-telegram-bot/requirements.txt
sudo chmod -R a+rX /opt/torbox-telegram-bot/.venv

sudo install -m 0600 .env /etc/torbox-telegram-bot.env
sudo install -m 0644 torbox-telegram-bot.service /etc/systemd/system/torbox-telegram-bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now torbox-telegram-bot
sudo systemctl status torbox-telegram-bot --no-pager
sudo journalctl -u torbox-telegram-bot -f
```

Сервис запускается от изолированного динамического пользователя. Ключ владельца хранится в `/etc/torbox-telegram-bot.env`, пользовательские ключи — в `/var/lib/torbox-telegram-bot/credentials.json`, а обычное состояние — в `/var/lib/torbox-telegram-bot/state.json`. Оба JSON-файла создаются с правами `0600` и не попадают в Git.

После обновления кода:

```bash
sudo cp torbox_tg_bot.py /opt/torbox-telegram-bot/torbox_tg_bot.py
sudo systemctl restart torbox-telegram-bot
```

## Проверки

Офлайн-тесты ничего не создают и не удаляют в TorBox:

```bash
.venv/bin/python -m py_compile torbox_tg_bot.py
.venv/bin/python -m unittest discover -s tests -v
```

Отдельный live smoke-тест обращается к NNM-Club и скачивает один `.torrent`, но не отправляет его в TorBox:

```bash
RUN_LIVE_TESTS=1 .venv/bin/python -m unittest tests.test_torbox_tg_bot.NnmSmokeTests -v
```

## iOS-приложение TorBox One

В `ios/` живёт нативное SwiftUI-приложение (iOS 26): найти на трекерах, скачать в TorBox, посмотреть — не выходя из приложения. Ключ TorBox хранится в Keychain телефона и отправляется только в `api.torbox.app`.

Что есть в интерфейсе:

- **Первый запуск.** Приветствие в четыре шага подключает TorBox и сервер поиска и проверяет их живым запросом; шаги можно пропустить и вернуться к ним в «Настройках».
- **Поиск.** Каталог Кинопоиска постерами 2:3 с рейтингом, подсказки по названию, история последних запросов, а на экране раздач — сортировка (по раздающим, размеру, качеству, названию), фильтры («только мгновенные», «1080p и выше», «с озвучкой») и добавление в TorBox прямо из строки. Долгий поиск по трекерам можно отменить; если все источники ответили ошибкой, экран говорит об этом, а не «ничего не нашлось».
- **Главная.** Сначала то, что смотришь: «Продолжить просмотр» с кадром из места остановки, «Недавно добавленное» постерами, недавние запросы и каталог. Поиск — в строке сверху, там же подсказка «уже есть в твоём TorBox».
- **Библиотека.** Список или постерная сетка (переключатель в тулбаре) с отметками просмотра, сортировка по дате, названию и размеру, сводка при активных закачках, разделы «Качаются» и «Готово», поиск по названию, свайпы (продолжить, реанонс, стоп-сид, удалить), уведомления TorBox с бейджем непрочитанных и добавление magnet-ссылки вручную. Приложение зарегистрировано как обработчик `magnet:` — ссылку можно открыть из браузера.
- **Раздача.** Одна главная кнопка «Смотреть/Продолжить» с нужной серией, серии сгруппированы по сезонам и отсортированы по-человечески, у файлов человеческие названия («Winter Is Coming» вместо `Game.of.Thrones.S01E01...mkv`), фильтр по файлам, состояние «просмотрено / продолжить с 12:34 / на телефоне».
- **Плеер.** Раскладка как у Infuse: закрыть и «вписать/заполнить» слева сверху, звук справа, тонкие круговые ±10 в центре, снизу — название серии, пилюля с настройками и списком серий, шкала во всю ширину. Очередь серий с автопереходом (отсчёт 5 секунд и «Остаться»), жесты (двойной тап ±10 с, вертикальный свайп — яркость и громкость), перелистывание по времени с переменной точностью (чем дальше палец от шкалы, тем мельче шаг) и кадром-превью для скачанных файлов, память позиции и выбранной озвучки, «Продолжаю с 41:12» с кнопкой «Сначала», управление с наушников и Пункта управления.
- **Офлайн.** Серия качается в память телефона, пока её смотришь (настройка «Качать при просмотре»), файлы видны в «Файлах», в «Памяти телефона» видно занятое место и можно всё удалить.
- **Метаданные.** Постеры, обложки, логотипы, рейтинг Кинопоиска, описание, жанры, актёры и русские названия серий подтягиваются по имени раздачи; библиотеку можно смотреть постерами или списком, а карточки «Продолжить просмотр» показывают кадр, снятый плеером с места остановки.
- **Мелочи.** Тёмная и светлая схемы, тактильный отклик, единые тосты вместо разнородных алертов, состояния загрузки скелетонами, поддержка Dynamic Type до accessibility-размеров (чипы переносятся, каталог становится одноколоночным) и подписи для VoiceOver.

Сборка (нужен Xcode и `brew install xcodegen`):

```bash
cd ios && xcodegen generate && open TorBoxOne.xcodeproj
```

Для установки на iPhone скопируй `ios/Local.xcconfig.example` в `ios/Local.xcconfig` и впиши свой Apple Team ID (Xcode → Settings → Accounts → команда → Team ID). Файл не попадает в Git, а настройка переживает `xcodegen generate`, потому что проект подключает `ios/Signing.xcconfig`.

### Мини-API поиска для приложения

`search_api.py` — FastAPI-мост, который переиспользует поиск и каталог бота (NNM, Prowlarr, Кинопоиск). Управления TorBox в нём нет. Локальный запуск:

```bash
.venv/bin/pip install -r requirements-api.txt
./scripts/run-search-api.sh
```

Читает тот же `.env`, что и бот, плюс `SEARCH_API_TOKEN` (bearer-токен для приложения; без него авторизация выключена — годится только для разработки), `SEARCH_API_HOST`/`SEARCH_API_PORT` (по умолчанию `127.0.0.1:8787`) и `SEARCH_API_STATE_DIR` — каталог для кэшей. На VPS он обязателен: рабочий каталог сервиса только для чтения, и без этой переменной кэши не сохраняются.

**Контракт всех эндпоинтов — [`docs/search-api.md`](docs/search-api.md)**: старые и новые, с формами запросов и ответов, ценой каждого действия в запросах к Кинопоиску и списком того, что нельзя ломать (этим же сервером пользуются бот и выпущенное приложение TorBox One). Живая проверка форм — `./scripts/live-check-search-api.sh`; он ходит к настоящим трекерам и тратит суточную квоту каталога, поэтому запускается руками.

### Метаданные: постеры, описания, названия серий

`meta_service.py` превращает имя раздачи в карточку тайтла: разбирает название (двойные названия через «/», год, «Сезон 4», технический хвост релиза), ищет совпадение в Кинопоиске и отдаёт постер, обложку, логотип, рейтинг, описание, жанры, состав и русские названия серий с синопсисами. Результаты кэшируются на диск (`meta_cache.json`, 30 дней), поэтому повторные открытия мгновенные и не тратят квоту API.

- `GET /meta/match?name=<имя раздачи>` — карточка тайтла (или `matched: false`, если каталог не узнал раздачу; лучше честное «не нашли», чем чужой постер).
- `GET /meta/{film_id}/episodes?season=N` — серии с названиями, описаниями и кадрами.

Кадров серий у Кинопоиска нет. Если задать `TMDB_API_KEY` (бесплатный ключ на themoviedb.org), сервер добавит к сериям кадры из TMDB. Без него приложение показывает номер серии, а для начатых серий — кадр, который плеер сам снял с того места, где ты остановился.

Деплой на VPS рядом с ботом: `torbox-search-api.service` (systemd, читает `/etc/torbox-telegram-bot.env`) + `Caddyfile.search-api` (HTTPS через Let's Encrypt; без домена подойдёт `<IP>.sslip.io`). В приложении адрес сервера меняется в «Настройках».

## Важное

- Старые результаты поиска живут один час, подтверждение добавления — 15 минут.
- При первом запуске бот запоминает существующие уведомления и не засыпает чат старой историей; затем присылает только новые.
- Удаление из TorBox окончательное, поэтому оно всегда требует отдельной кнопки подтверждения.
- Ограничения размера и количества активных загрузок зависят от тарифа TorBox.
- Пользователь сам отвечает за законность доступа и наличие прав на конкретный материал.
