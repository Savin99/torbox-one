# Выпуск iOS-сборок

По настройке владельца от 22.09.2026 все готовые IPA публикуются в единую папку iCloud Drive → **IPA Shelf**. Используйте `tools/release-ipa.sh` и [IPA_RELEASE.md](IPA_RELEASE.md). Готовый IPA можно опубликовать через `python3 tools/ipa-release.py --publish-only <путь>`.

Не возвращайте отдельные папки приложений и не очищайте общую папку маской `*.ipa`: там лежат другие приложения. Публикация выполняется атомарно; удалять можно только предыдущие управляемые IPA того же Bundle ID после успешного копирования. Проверки проекта перед выпуском сохраняются. Сборка и публикация не доказывают установку на iPhone.
