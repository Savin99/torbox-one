## Основание: предоставленная запись

Запись длится около 71 секунды. В начале показан другой Telegram-бот, затем текущий TorBox. Это визуальный референс; сообщения и инструкции внутри видео не использовались как разрешение на действия.

1. **Меню примера — в целом удачно.** Есть явный вход в поиск, история и избранное. Кнопок много, часть относится к рекламе и сторонним сервисам.
2. **Поиск с постерами — удачно.** Название, год и обложка помогают отличить фильмы до выбора.
3. **Видео примера — ясное основное действие.** Под видео расположены озвучка, качество и обновление. Наличие видео в чужом боте не доказывает, что большой файл можно отправить нашим способом через Bot API.
4. **Главная TorBox — требует сокращения.** Много текста о механике кнопок; в чате остаются похожие экраны с пометкой «через бота».
5. **Выдача TorBox — требует упрощения.** Длинные имена файлов и кнопки «➕ 1» усложняют выбор. У экранных копий 1080p не объясняется ограничение качества.
6. **Возврат в меню — недостаточно контекста.** На записи появляются повторяющиеся меню. Библиотека, ошибки и реальное скачивание на записи не показаны; выводы об этих сценариях основаны на коде и новых офлайн-проверках.

## Что реализовано

- Главная объясняет задачу, а не устройство интерфейса. Без аккаунта первым действием становится подключение TorBox.
- Обычный текстовый поиск работает без inline mode и каталога. Ошибка каталога позволяет перейти прямо к трекерам.
- На странице три релиза; у каждого указаны качество, озвучка, размер, доступность и подписанное добавление. CAM/TS обозначены как экранные копии.
- Фильтры: все, кэш TorBox, 1080p+ без CAM/TS; сортировка по размеру. Фильтрация сохраняет исходный ID выбранного результата. Возврат из подробностей сохраняет страницу.
- История последних восьми запросов и до двадцати избранных названий сохраняются между перезапусками отдельно для каждого Telegram ID. Избранное запускает актуальный поиск по названию.
- При полном отказе источников показывается ошибка доступности. «Повторить» выполняет тот же запрос, включая после перезапуска; возврат к старой выдаче больше не подменяет повтор поиска.
- Каждая выдача получает собственную версию. Старые кнопки добавления показывают переход к актуальной выдаче; они не добавляют другой фильм с тем же индексом. Старые клавиатуры без версии тоже требуют повторного выбора.
- Добавление ведёт в созданную загрузку. Короткая запись об успешном добавлении подавляет повторные нажатия, пока список TorBox ещё не обновился. Она очищается при смене аккаунта и при удалении соответствующей загрузки.
- Библиотека разделена на все / готово / в процессе. Карточки подписаны названиями вместо технических TorBox ID. Удаление находится внутри карточки и по-прежнему требует подтверждения точной загрузки.
- Готовая загрузка открывает постраничный список файлов с естественной сортировкой: серия 2 идёт перед серией 10. Кнопка файла запрашивает ссылку для точных torrent_id/file_id; доступность и принадлежность файла проверяются заново.
- В Telegram попадает разрешённая HTTPS-ссылка на файл, а не URL запроса с API-ключом. Ошибки этого запроса не показывают ключ. Готовность загрузки учитывает `download_present`.
- Личные загрузки, история, настройки и ссылки не выводятся в inline-сообщениях, которые могут находиться в группе. Для добавления из inline-карточки ссылка в личный чат сохраняет выбранный релиз.
- Автоуведомления и предупреждения о зависшей загрузке можно отключить для своего Telegram ID.
- При обновлении сообщения без кнопок старая клавиатура явно удаляется; восстановление после недоступного сообщения запоминает новый экран.
- По уточнению пользователя от 8 сентября обычные входящие сообщения сохраняются. На новый запрос создаётся новый ответ бота, а его загрузка и навигация редактируются на месте. Выбранная inline-карточка пользователя остаётся неизменной; результаты отправляются ботом отдельно в личный чат. Старые кнопки inline-карточек и карточки с `via_bot` тоже не редактируют исходное сообщение. Удаляется только API-ключ при его отправке в режиме подключения аккаунта.

## Подбор качества, озвучки и сезонов

- По умолчанию — 1080p, дубляж, приоритет полных сезонов и комплектов. Доступная раздача выше раздачи без сидов и кэша; подходящее качество выше общего рейтинга, количества сидов и бонусов за 4K. В одном качестве полный сезон выше отдельных серий; затем учитываются выбранная озвучка, охват комплекта, кэш и сиды.
- Кнопка настроек доступна на главной и в результатах, также есть `/settings`. Качество: 720p / 1080p / 4K / любое. Озвучка: дубляж / многоголосая / двухголосая / LostFilm / HDRezka / любая. Альтернативы можно скрыть. Настройки сохраняются отдельно для каждого пользователя; выдача пересортировывается без повторного запроса, выбранный сезон сохраняется, старые кнопки добавления становятся недействительными.
- Все полученные кандидаты сохраняются для выбора сезона и альтернатив. Снято прежнее обрезание Telegram-выдачи: поздние сезоны не теряются из-за множества вариантов первого. Комплекты и по одному варианту недостающих сезонов появляются до повторяющихся изданий.
- Год премьеры сериала больше не добавляется к запросу после выбора в каталоге, чтобы следующие сезоны с другими годами тоже находились. Для фильмов год сохранён.
- Меню сезонов распознаёт русские и английские обозначения, диапазоны и списки. В нём доступны комплект, все найденные сезоны и каждый сезон отдельно. Пропущенные номера и отдельные серии обозначены явно. DUAL не считается доказательством дубляжа; поле «Перевод» источника важнее имени файла.
- Это покрытие полученных релизов, а не полный каталог вышедших сезонов. Лимиты и доступность самих источников сохраняются; релиз без явного перечня серий нельзя считать проверенным полным сезоном.

## Проверенный путь в локальном демо

Демо вызывает те же обработчики, что и Telegram, с подставными TorBox и поиском. Оно служит для проверки содержимого и переходов, а не воспроизводит пиксельно оформление Telegram.

1. **Главная — пройдено:** основные действия доступны, текст короткий.
2. **Поиск и фильтр — пройдено:** три результата, переключение «В кэше» сохраняет выбранные релизы.
3. **Добавление — пройдено:** один клик, подтверждение содержит «Открыть загрузку».
4. **Карточка загрузки — пройдено:** готовое состояние ведёт к файлам.
5. **Список серий — пройдено:** переход на вторую страницу показывает серии 7–9.
6. **Файл и возврат — пройдено:** выбрана серия 8, показана кнопка ссылки; возврат открывает вторую страницу файлов.

## Проверки и границы

`python -m unittest discover -s tests`: 144 теста, 143 успешных, 1 сетевой тест пропущен. Проверены HTML-экранирование и лимиты callback_data, устаревшие кнопки, повтор добавления, фильтры и возврат, история и изоляция аккаунтов, отказ каталога и трекеров, точные ID файлов, недоступные файлы, inline-переходы и отключение уведомлений. Отдельно проверены рейтинг 1080p/дубляжа, сохранение 12 сезонов среди 42 кандидатов, комплекты, неполные сезоны, приоритет доступных раздач при подборе следующего сезона, DUAL/DUB/DVO, настройки после перезапуска, смена предпочтений без сети и сохранение выбранного сезона. Для исправления сообщений проверены отдельный ответ на выбор inline-карточки, защита ID сообщения с `via_bot`, сохранение обычных запросов и предыдущих ответов, обновление только сообщения бота и совместимость со старым сохранённым ID экрана. `py_compile` и `git diff --check` прошли.

Через HTTP локального демо пройден сценарий: запрос «Сериал» → комплект 1–8 в 1080p с дубляжом первым → меню девяти сезонов → сезон 8 → смена на 4K/MVO → тот же сезон с новым порядком → пустая строгая выборка → сброс настроек. Ответы сохранены локально в `bot-ux-qa/search-settings-http.json` (исключены из Git).

В браузере проверен путь выше и просмотрено пустое состояние истории в ширине 390 px. Точная высота кнопок, контраст выбранной темы, VoiceOver, масштабирование шрифта и клиентское поведение Telegram требуют проверки в Telegram. Скриншоты не доказывают доступность интерфейса для всех пользователей.

Авторизация Telegram подтверждена после деплоя. Не проверены реальные запросы на добавление/удаление, получение CDN-ссылки и воспроизведение видео на телефоне. Бот выдаёт ссылку для открытия или скачивания; отдельная отправка большого видео внутрь чата не реализована. Длительный сетевой поиск остаётся синхронным и не поддерживает отмену во время запроса.

Прямой запрос «Тед Лассо» к публичному NNM с локального Mac вернул HTTP 403. После деплоя тот же запрос с VPS прошёл: NNM вернул 15 результатов, Prowlarr — 36; после фильтрации и удаления дублей осталось 37 релизов с обозначениями сезонов 1–4. Наличие обозначения сезона не подтверждает его официальный выход или полноту. В первых результатах — 1080p; озвучка и неполные сезоны определяются по сведениям источника. Запросов добавления в TorBox не выполнялось. Повторный визуальный проход новых настроек пока недоступен: Mac заблокирован. Ранее проверенный визуальный путь описан выше.
