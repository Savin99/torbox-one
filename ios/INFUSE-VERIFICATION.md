# Проверка локального сценария на iPhone

Нужны Xcode 26+, iPhone и Infuse 8.4.7 или новее. Использовать собственное тестовое видео; для проверки серий — небольшую раздачу с двумя сезонами, минимум двумя сериями в каждом и внешними субтитрами.

## Автоматические проверки

В Xcode: схема `TorBoxOne` → Product → Test. Либо после `xcodegen generate`:

```bash
xcodebuild test -project TorBoxOne.xcodeproj -scheme TorBoxOne \
  -destination 'platform=iOS Simulator,name=<доступный iPhone>' CODE_SIGNING_ALLOWED=NO
```

`TorBoxOneTests` проверяет выбор одного сезона, произвольных серий, порядок и отсутствие дубликатов, отсутствие обрезания длинного сезона, передачу `download=1`, кодирование ссылок/имён/субтитров, частичные ошибки, повторные и чужие callbacks, сохранение сеанса после перезапуска. Никаких обращений к TorBox или скачиваний видео в этих тестах нет.

## Проверка полного сценария

| Шаг | Ожидаемый результат |
|---|---|
| Infuse не установлен: выбрать файл для скачивания | Экран установки; никакого запуска встроенного плеера или стриминга |
| Установить Infuse, вернуться и продолжить | Выбранные файлы сохранены в ожидающем запросе, запрашиваются свежие ссылки |
| Добавить раздачу, которая ещё качается в TorBox | Локальное скачивание недоступно до готовности раздачи |
| В раздаче с двумя сезонами выбрать сезон 2 | Главная кнопка и список относятся к сезону 2; сезон 1 не отправляется |
| Отметить серии 2 и 4 | В запросе только эти две серии, их количество и размер видны до отправки |
| Выбрать полный сезон из 20+ серий | Infuse получает все выбранные серии, а не первые 12 |
| Отменить подготовку ссылок | Infuse не открывается, часть сезона не отправляется |
| Скачать небольшой фильм | В Infuse начинается загрузка; ответ приложению называется «Передано», а не «Скачано» |
| Дождаться загрузки и включить авиарежим | Видео открывается из локальных файлов Infuse без обращения к TorBox |
| Остановить видео, закрыть и снова открыть Infuse | Продолжение с сохранённой Infuse позиции, язык и субтитры выбираются в Infuse |
| Досмотреть сезон | Непрерывное воспроизведение использует локальные серии при включённой настройке Infuse |
| Удалить сезон в Infuse | Удаляется локальная копия; облачная раздача остаётся. Для немедленного освобождения места проверить «Недавно удалённые» в «Файлах» |
| Скачать следующий сезон | Первый сезон не скачивается повторно |
| Передать старый файл TorBox One через «Поделиться» | Infuse получает доступ к копии; исходник не удаляется автоматически |
| Закрыть TorBox One системой во время перехода, затем получить callback | Сеанс восстанавливается; подписанные CDN-ссылки и ключ TorBox не хранятся в файле сеанса |
| Ошибка части файлов при передаче в Infuse | Повтор касается только файлов, перечисленных в `failedUrl` |

## Что этот API не позволяет проверить из TorBox One

Готовность локальной загрузки, состояние памяти, позиция просмотра и удаление файлов доступны внутри Infuse. Приложение не получает эти данные и не подменяет их собственными статусами. «Смотреть скачанное» открывает Infuse без передачи URL удалённого видео; выбор конкретной локальной копии происходит в Infuse.

## Статус при подготовке изменения

Проверены конфигурация XcodeGen/Info.plist и отсутствие новых ошибок синтаксического разбора относительно исходной версии. Сборка и XCTest на iOS **не выполнены**: Linux-сервер не имеет Xcode, а GitHub Actions отказался запускать macOS runner с сообщением `The job was not started because your account is locked due to a billing issue.` Проверка на физическом iPhone с Infuse также остаётся открытой.
